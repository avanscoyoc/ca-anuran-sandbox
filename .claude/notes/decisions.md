- **2026-10-02** Geographic range (user): **inference-time only, never a training input**. The user gives the recorder lat/lon, and CWHR range maps (CDFW BIOS, **range only, not habitat suitability**, CC-BY) adjust each class's score after the head: `logit + log(w)`, with w = 1 inside the range and a floor ε outside. The main goal is to resolve confusable pairs and acoustic groups (PACH, WETO, MYLF) toward the species whose range contains the site. Format: GeoJSON (WGS84), downloaded once; distances computed in EPSG:3310. Site coordinates for the ARU sets are easy for the user to get, so E7 can be tested on Tier B.
- **2026-10-02** Range maps organized as their own non-audio source: raw GeoJSON in `data/raw/range/cwhr/<dsN>.geojson` (unchanged), class → CNRA package in `configs/ranges.yaml` (not an audio data card; the catalog only reads `configs/datasets/`), one module + task `anuran.data.ranges` / `pixi run ranges`. Habitat-suitability ("Predicted Habitat") packages are rejected in code. Groups get the union of their members' ranges; a group with any unmapped member (PACH, because PSHY has no CWHR map) gets no prior. Prior parameters are provisional (scale 20 km, floor 0.02) until E7 on Tier B.
- **2026-10-03** PSHY range = USGS GAP range map aBCTRx (user found it; ScienceBase 59f5e1b7e4b063d5d307da87). Sources: CWHR is the default, and GAP is used only where CWHR has no map. GAP habitat maps are rejected the same way as CWHR "Predicted Habitat". A GAP map is used only if every HUC12 is Known/extant, because the shipped polygon is dissolved and can't be filtered. The "in California" footprint in the check uses the CWHR maps only, because GAP maps cross the state line. ds1165 "California Treefrog" is PSCA (*P. cadaverina*), not PSHY.
